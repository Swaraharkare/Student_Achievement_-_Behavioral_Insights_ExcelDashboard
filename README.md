# Student Achievement & Behavioral Insights Dashboard

A dynamic, interactive data visualization project built entirely within **Microsoft Excel** to analyze student performance and behavioral data.

## Dashboard Screenshot

## Overview

This dashboard helps identify key trends in student data, such as the relationship between study habits and scores, and attendance patterns across different grade levels. All interactivity is driven by native Excel Slicers.

## Technical Details

This project was built using standard Microsoft Excel features. No external tools, programming languages (like Python or VBA), or third-party add-ins were used.
## Data Sources

The raw data used for this dashboard is a publicly available dataset.

**Dataset Link:** -<a href="https://www.kaggle.com/datasets/kundanbedmutha/student-performance-dataset">Student Performance Dataset</a>

## How to Use

1.  Clone this repository.
2.  Open the Excel file in MS Excel.
3.  Use the interactive **slicers** on the right side to explore the data.
